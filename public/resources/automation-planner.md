# Automation discovery worksheet

Use this to map a workflow before building it. Do not paste passwords, API keys or private customer data into a shared brief.

## Current process
What triggers the work? List each step, who does it, and where it happens.

## Desired outcome
What should happen automatically? What must a person still review or approve?

## Inputs
Which systems provide data? Who owns each account? How often does data change?

## Exceptions
What if a field is missing, a message bounces, or an API is unavailable? What should stop rather than retry?

## Privacy and access
What personal data is involved? Who may see it? How long should it be kept?

## Test cases
Give a normal example, a duplicate, an incomplete record, and a failure case using safe test data.

## Handover
Who will monitor the automation, fix failures, and rotate credentials?
